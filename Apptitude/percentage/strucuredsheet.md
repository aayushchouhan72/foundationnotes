# 📘 PERCENTAGE FORMULA SHEET

## 1. Basic Percentage

### Percentage of a number

[
\boxed{x% \text{ of } N=\frac{x}{100}\times N}
]

### What percentage is A of B?

[
\boxed{\frac{A}{B}\times100}
]

### Find the number

If (x%) of a number (N) is (A):

[
\boxed{N=\frac{A\times100}{x}}
]

---

# 2. Fraction ↔ Percentage

### Fraction to percentage

[
\boxed{\frac{a}{b}\times100%}
]

### Percentage to fraction

[
\boxed{x%=\frac{x}{100}}
]

Useful conversions:

[
10%= \frac1{10}
]

[
20%= \frac15
]

[
25%= \frac14
]

[
50%= \frac12
]

[
75%= \frac34
]

[
12.5%= \frac18
]

[
33\frac13%=\frac13
]

[
66\frac23%=\frac23
]

---

# 3. Percentage Increase

[
\boxed{%Increase=\frac{Increase}{Original}\times100}
]

where

[
Increase=New-Original
]

### New value after (x%) increase

[
\boxed{New=Original\left(1+\frac{x}{100}\right)}
]

or

[
\boxed{New=Original\times\frac{100+x}{100}}
]

---

# 4. Percentage Decrease

[
\boxed{%Decrease=\frac{Decrease}{Original}\times100}
]

where

[
Decrease=Original-New
]

### New value after (x%) decrease

[
\boxed{New=Original\left(1-\frac{x}{100}\right)}
]

or

[
\boxed{New=Original\times\frac{100-x}{100}}
]

---

# 5. Reverse Percentage ⭐

### After (x%) increase, final value is given

[
\boxed{Original=\frac{Final\times100}{100+x}}
]

### After (x%) decrease, final value is given

[
\boxed{Original=\frac{Final\times100}{100-x}}
]

This is one of the most important patterns in your sheet.

---

# 6. Remaining Percentage ⭐

After (x%) decrease:

[
\boxed{Remaining%=100-x}
]

So:

[
\boxed{Remaining\ Value=Original\times\frac{100-x}{100}}
]

Example: 20% decrease

[
Remaining=100-20=80%
]

Therefore:

[
New=Original\times\frac{80}{100}
]

👉 **Denominator is always 100** for percentage calculations.

---

# 7. Percentage Comparison ⭐

### A is what % more than B?

[
\boxed{\frac{A-B}{B}\times100}
]

### A is what % less than B?

[
\boxed{\frac{B-A}{B}\times100}
]

⚠️ **The number after “than” is the base/denominator.**

Example:

A = 120, B = 100

A is:

[
\frac{120-100}{100}\times100=20%
]

more than B.

But B is:

[
\frac{120-100}{120}\times100=16\frac23%
]

less than A.

---

# 8. Successive Percentage ⭐⭐⭐

## Two successive increases

If increases are (a%) and (b%):

[
\boxed{Net\ Increase=a+b+\frac{ab}{100}}
]

---

## Two successive decreases

[
\boxed{Net\ Decrease=a+b-\frac{ab}{100}}
]

---

## Increase by (a%), then decrease by (b%)

[
\boxed{Net\ Change=a-b-\frac{ab}{100}}
]

If result is negative → decrease.

---

## Decrease by (a%), then increase by (b%)

[
\boxed{Net\ Change=b-a-\frac{ab}{100}}
]

The sheet contains several successive increase/decrease patterns.

### Safest method for multiple changes:

[
\boxed{Final=Original\times\frac{100\pm a}{100}\times\frac{100\pm b}{100}}
]

---

# 9. Same Expenditure / Same Cost ⭐

If:

[
Price\times Quantity=Constant
]

then:

[
\boxed{P_1Q_1=P_2Q_2}
]

### If price increases by (x%)

Required decrease in consumption:

[
\boxed{\frac{x}{100+x}\times100%}
]

### If price decreases by (x%)

Possible increase in consumption:

[
\boxed{\frac{x}{100-x}\times100%}
]

This is a recurring pattern in your sheet.

---

# 10. Ratio and Percentage

If:

[
A:B=a:b
]

Then percentage of A in total:

[
\boxed{\frac{a}{a+b}\times100}
]

Percentage of B in total:

[
\boxed{\frac{b}{a+b}\times100}
]

### Percentage to ratio

If A is (x%) of B:

[
\boxed{A:B=x:100}
]

Then simplify.

---

# 11. Income, Expenditure & Savings ⭐

[
\boxed{Income=Expenditure+Savings}
]

Therefore:

[
\boxed{Savings=Income-Expenditure}
]

[
\boxed{Expenditure=Income-Savings}
]

For percentage questions, first convert each quantity into (100%) or an algebraic variable, then apply the percentage change. The sheet uses this pattern repeatedly.

---

# 12. Population

### After (x%) annual growth for (n) years:

[
\boxed{P_n=P\left(1+\frac{x}{100}\right)^n}
]

### After (x%) annual decrease:

[
\boxed{P_n=P\left(1-\frac{x}{100}\right)^n}
]

---

# 13. Marks / Examination

### Percentage marks

[
\boxed{\frac{Obtained\ Marks}{Maximum\ Marks}\times100}
]

### Obtained marks

[
\boxed{\frac{Percentage}{100}\times Maximum\ Marks}
]

### Maximum marks

[
\boxed{\frac{Obtained\ Marks\times100}{Percentage}}
]

---

# 14. Pass / Fail Questions

If passing percentage = (p%):

[
\boxed{Passing\ Marks=\frac{p}{100}\times Maximum\ Marks}
]

If a student fails by (x) marks:

[
\boxed{Passing\ Marks=Student's\ Marks+x}
]

If a student passes by (x) marks:

[
\boxed{Passing\ Marks=Student's\ Marks-x}
]

The sheet has many examination and pass/fail variations.

---

# 15. Election / Voting

### Percentage of votes

[
\boxed{\frac{Votes\ Obtained}{Total\ Valid\ Votes}\times100}
]

### Votes from percentage

[
\boxed{Votes=\frac{Percentage}{100}\times Total}
]

For candidate comparison:

[
\boxed{%Difference=\frac{Difference}{Required\ Base}\times100}
]

---

# 16. Population / Students / Voters

Same basic formula:

[
\boxed{Part=\frac{Percentage}{100}\times Total}
]

[
\boxed{Percentage=\frac{Part}{Total}\times100}
]

[
\boxed{Total=\frac{Part\times100}{Percentage}}
]

This single formula covers a huge number of questions in the sheet.

# 17. Percentage Change in a Fraction ⭐

If:

[
X=\frac{A}{B}
]

and numerator changes by (x%), denominator by (y%), use:

[
X\_{new}
=======

X\times
\frac{100\pm x}{100}
\times
\frac{100\pm y}{100}
]

Then:

[
\boxed{%Change=\frac{X_{new}-X}{X}\times100}
]

The Level-II section contains this kind of advanced fraction-change problem.

# 18. Percentage of Percentage

[
\boxed{x%\text{ of }y%=\frac{x}{100}\times\frac{y}{100}}
]

Example:

[
20%\text{ of }30%
=================

\frac{20}{100}\times\frac{30}{100}
=6%
]

# 19. Mixture / Concentration

### Percentage concentration

[
\boxed{\frac{Quantity\ of\ component}{Total\ Quantity}\times100}
]

### Pure quantity

[
\boxed{Total\times\frac{Percentage}{100}}

The later exercises apply percentages to mixture and concentration situations.

### ⚡ One rule to never forget

**“Percentage = something out of 100.”**

So whenever you see:

**20% of 500**

think:

[
500\times\frac{20}{100}
]

]

That **100 in the denominator** is your constant friend. 😄
